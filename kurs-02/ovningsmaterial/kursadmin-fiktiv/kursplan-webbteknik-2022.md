# Kursplan – Webbteknik grund (FIKTIV, version från 2022)

Yrkeshögskolan Exempelia
Omfattning: 3 sp

## Lärandemål
Efter avslutad kurs kan den studerande:
- skriva strukturerad HTML och CSS
- förklara hur en webbsida laddas i en webbläsare
- publicera en enkel sida
- resonera kring tillgänglighet

## Innehåll
Modul 1: HTML-struktur (8 h)
Modul 2: CSS och layout (12 h)
Modul 3: Publicering och verktyg (8 h)
Modul 4: Tillgänglighet (6 h)

## Programvara
Visual Studio Code, Chrome eller Internet Explorer 11.
FTP-klient för publicering.

## Examination
Inlämningsuppgift 1 (30 %), inlämningsuppgift 2 (30 %), sluttest (40 %).
Deadline för samtliga: 15.12.2022.

## Regel om AI-verktyg
All användning av AI-verktyg vid inlämningsuppgifter är förbjuden.
