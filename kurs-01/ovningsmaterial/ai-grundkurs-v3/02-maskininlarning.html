Modul 2 – Maskininlärning

Maskininlärning innebär att ett program lär sig mönster ur data i stället för att programmeras med explicita regler.

2.1 Tre huvudtyper

  1. Övervakad inlärning – modellen tränas på data med facit.
  2. Oövervakad inlärning – modellen hittar struktur i data utan facit.
  3. Förstärkningsinlärning – modellen lär sig genom belöning och bestraffning.

2.2 Verktyg vi använder i kursen

Vi använder Python 3.7 tillsammans med biblioteken scikit-learn och TensorFlow 1.x. Installationsanvisningar finns på kursens Moodle-sida.

Studerande som inte har Python installerat kan använda Google Colab.

2.3 Fallstudie

Ett fiktivt företag, Nordkraft Ab, vill förutsäga elförbrukning. Vilken typ av maskininlärning passar bäst? Motivera.

2.4 Fördjupning

Läs vidare i modulen om djupinlärning för mer information om neurala nätverk.
